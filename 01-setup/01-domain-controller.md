# 01 - Domain Controller Setup

## Objective
Build and configure a Windows Server Domain Controller for the help desk homelab environment.

---

# Environment Information

| Component | Value |
|---|---|
| Hypervisor | VirtualBox |
| Server OS | Windows Server 2025 |
| Hostname | DC |
| Domain Name | brycefalker.com |
| IP Address | 172.16.0.10 |
| RAM | 4-8 GB |
| CPU | 2 vCPUs |

---

# VM Configuration

## VirtualBox Settings
- Generation: [N/A]
- Network Adapter: NAT and Internal Adapter
- Storage Size: 60 GB
- ISO Used: Windows Server 2025 ISO

---

# Windows Server Installation

## Steps
1. Create a new VM
2. Attach Windows Server ISO
3. Configure RAM/CPU and storage space
4. Install Windows Server
5. Set Administrator password
6. Rename the computer to DC01
7. Restart server
