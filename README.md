# Help Desk Homelab

This repository documents my IT help desk homelab environment used to practice:

- Active Directory
- Group Policy
- Microsoft 365 Administration
- osTicket Ticketing System
- Windows 11 Administration
- macOS Support
- Network Configuration
- User and Device Management

- Windows 11 Workstations

- Entra Connect Server
